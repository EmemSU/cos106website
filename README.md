**Course:** COS 106 – Introduction to Web Technologies

## Project Overview
This is a responsive, multi-page personal academic portfolio and student management web application built with **HTML5, CSS3, and Vanilla JavaScript**. It showcases my educational background, technical skills, software projects, and includes an interactive Academic Planner and validated Contact Form.

## Features & Pages
1. **Home (`index.html`):** Features my introduction, profile portrait, and an HTML5 `<audio>` voice welcome message.
2. **About Me (`about.html`):** Highlights my educational journey (MIVA Open University & University of Regina), Software Manager career aspiration, technical skills, hobbies, and a semantic HTML `<table>` of current major courses.
3. **Projects (`projects.html`):** Displays three featured projects using responsive Flexbox cards with descriptions, tech tags, and hover animations.
4. **Academic Planner (`acaplan.html`):** An interactive JavaScript task manager allowing users to add tasks, mark them as completed, and delete them dynamically using DOM manipulation and arrays.
5. **Contact (`contact.html`):** A responsive contact form with custom JavaScript validation ensuring no empty fields, valid email formatting, and numeric-only phone numbers.

## Technologies Used
* **HTML5:** Semantic structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), forms, tables, and multimedia (`<audio>`).
* **CSS3:** External stylesheet (`css/style.css`), Flexbox layouts, media queries for mobile responsiveness, CSS transitions/hover effects, and a consistent dark plum/purple theme.
* **JavaScript (ES6):** Event listeners, DOM manipulation, array state management, and form validation logic.
